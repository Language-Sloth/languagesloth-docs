> **Language Sloth** is a large language-learning Discord community. This documentation library explains how the community is governed, how rules are enforced fairly, and how official decisions are published and preserved.

## What this library is for

- **Transparency:** make the governance structure and decision-making process easy to understand.
- **Consistency:** keep moderation, legal process, and official acts in one canonical place.
- **Accountability:** document responsibilities and procedures so they can be applied predictably.
- **Continuity:** preserve institutional memory as the community grows (staff turnover, new initiatives, new regions).

## Community overview

Language Sloth is organized around:

- **The Discord community:** the main social and learning hub.
- **Marketplace:** [store.languagesloth.org](http://store.languagesloth.org)
- **Advertising platform:** [advertise.languagesloth.org](http://advertise.languagesloth.org)
- Minecraft Server: [[mc-smp.languagesloth.org]]
## How to use this documentation

- If you are **new**: start with **Server rules** and **Community legal process**.
- If you are **staff**: review **Government structure** first, then use **Decrees & Acts** / **Organic Law** for formal decisions.
- If you are looking for the **“current rules”**: treat these pages as canonical references; Discord posts/announcements should link back here.

## Definitions (quick glossary)

- **Decree / Ministerial Act:** an official instrument used to ratify, create, or modify institutional rules and operational procedures.
- **Organic Law:** a foundational governance text defining competence, procedures, and guardrails (especially for the Senate).
- **Impeachment proceeding:** the formal process for judging alleged abuse or incompatible conduct by a Moderator (as defined in the Organic Law).

## Versioning note

When major changes occur, prefer to add a new decree/act and keep older ones archived in the **Official decrees & ministerial acts** page to preserve historical context.
